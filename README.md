# PLP Python Week 4

This assignment practices Python functions, parameters, return values, and default parameters.

- `welcome.py` - Contains a welcome() function that returns a greeting for a given name.
- `toolbox.py` - Contains double(), is_pass(), and greet() functions for practicing parameters and return values.

The hardest function to write was `greet()` because it uses a default parameter for the greeting.
It was useful to learn how a function can use a default value when no second argument is provided.
